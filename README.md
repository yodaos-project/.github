# YodaOS Project

👋 欢迎来到 **YodaOS Project** 组织！

## 什么是 YodaOS？

[YodaOS](https://github.com/yodaos-project/yodaos) 是由 [Rokid](https://www.rokid.com/) 发起的一款面向下一代智能交互设备的开源操作系统。它以 Linux 为基础，拥抱 Web 社区，使用 JavaScript 作为应用开发语言，并提供完整的从内核、硬件抽象层、AI 能力层到 JS 应用框架的全栈方案，帮助开发者快速构建语音交互类的 AI 应用。

主要特点：

- **全栈设计**：涵盖内核、AI 能力抽象、应用框架，方便快速开发 AI 应用。
- **语音优先**：针对语音交互场景做了大量优化，即使在强噪声环境下也能保持稳定、低延迟的语音唤醒与识别体验。
- **多平台支持**：可运行于高通、三星、联发科、博通等主流芯片和硬件平台。
- **开放生态**：完全开源，方便开发者自定义和扩展 AI 能力，与 Rokid 生态的内容与服务无缝集成。

## 本组织包含哪些内容

`yodaos-project` 组织托管了 YodaOS 相关的所有开源子项目，包括但不限于：

- 系统内核（Kernel）与 Bootloader（Uboot）相关代码
- AI 抽象层（AIAL）及常用算法库
- 系统服务（如网络管理、传感器服务、电源管理等）
- JavaScript 应用框架与 SDK
- 配套文档与工具链

欢迎浏览各个仓库了解更多细节，也欢迎大家提交 Issue 或 Pull Request 参与共建。
