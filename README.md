# YodaOS Project

👋 Welcome to the **YodaOS Project** organization!

## What is YodaOS?

[YodaOS](https://github.com/yodaos-project/yodaos) is an open-source operating system for next-generation interactive devices, initiated by [Rokid](https://www.rokid.com/). It is built on Linux, embraces the Web community, and uses JavaScript as the application development language. It provides a complete full-stack solution — from the kernel, hardware abstraction layer, and AI capability layer, to the JS application framework — helping developers quickly build voice-driven AI applications.

Key features:

- **Full-stack design**: Covers the kernel, AI capability abstraction, and application framework, enabling rapid development of AI applications.
- **Voice-first**: Heavily optimized for voice interaction scenarios, delivering stable, low-latency wake-word detection and recognition even in noisy environments.
- **Multi-platform support**: Runs on mainstream chips and hardware platforms from Qualcomm, Samsung, MediaTek, Broadcom, and more.
- **Open ecosystem**: Fully open source, making it easy for developers to customize and extend AI capabilities, with seamless integration into the Rokid ecosystem of content and services.

## What this organization contains

The `yodaos-project` organization hosts all open-source sub-projects related to YodaOS, including but not limited to:

- Kernel and bootloader (Uboot) related code
- AI abstraction layer (AIAL) and common algorithm libraries
- System services (such as network management, sensor services, power management, etc.)
- JavaScript application framework and SDK
- Supporting documentation and toolchains

Feel free to browse the repositories for more details, and contributions via issues or pull requests are welcome.
